# 1인 사전 시험 결과 · 빈 서식

이 파일을 복사한 뒤 실제로 해 본 항목만 채웁니다. 현재 모든 결과는 비어 있습니다. 빈칸은 성공·실패·0건을 뜻하지 않습니다. 이름·계정·개인정보·검색어는 적지 않습니다.

- 익명 코드: `PILOT01` (사전 배정 코드)
- 진행일: ____________________
- 사용한 EasyWeb 버전/빌드 파일: ____________________
- Chrome 버전 / OS: ____________________
- 제공된 패키지 SHA256: ____________________ (모르면 `UNKNOWN`)
- 시험을 시작하지 않았다면: `미실시`라고 적고 아래 결과를 채우지 않습니다.

각 칸은 해당 표현을 골라 씁니다.

- 도달: `도달 / 미도달 / 접근 차단 / 중단 / 미실시`
- 실제 카드 동작: `바로 이동 / 원본 위치 안내 / 카드 없음 / 화면 안 열림 / 미시도`
- 안내 이해: `예 / 아니요 / 잘 모르겠음`
- 시작 화면 복귀: `예 / 아니요 / 미시도`
