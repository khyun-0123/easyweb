# v7-v2 첫 독립 실패 진단 — 동결 v0.5.0

첫 결과는 **FAIL: 정확도 6/12(50%), 재현율 4/15(26.7%)**다. 5개 사이트 모두 사이트별 인수 조건에 미달한다. 최초 보고서·자료·엔진을 수정하거나 재실행하지 않았다. 이 문서는 저장된 첫 보고서와 fixture/정답/소스의 정적 검토다. 엔진 14파일과 자료 11파일은 동결 해시와 일치한다.

32개 accepted 제어에 실제 검색 입력 1개가 더해진 총 33개와 수집 수가 일치한다. 분류 전 개별 trace는 없으므로 개별 수집 성공을 별도 실행으로 입증한 것은 아니지만, 이번 보고서에서 수집 누락을 원인으로 확정할 근거는 없다. **다섯 페이지 모두 분류 수=표시 수이며 표시가 최대 5개**다. 6칸 제한 때문에 밀린 기대 기능은 관찰되지 않았다.

## 코드에 연결한 원인

다음은 실행 trace가 아닌 **정적 코드와 실제 fixture의 높은 확신 추론**이다. 세부 경로·행 번호·불일치 차원은 [JSON 진단](v7-failure-diagnosis.json)에 남겼다.

- **긴 서비스 카드:** 안전한 이름 추출이 카드의 제목·날짜·장소·상태를 합친다. city의 예약 카드는 36자를 넘어 일반 문구 점수 60에서 15가 깎여 채택 55에 못 미치는 45가 된다. 별도 카드 보강은 `제목 자식 + p` 구조만 받아 실제 `div/strong/div/span` 카드에 적용되지 않는다. (`analyzer.ts:50–74,267–277`, `classifier.ts:254–259,403–406,452`)
- **원본 탭 구조·주제 문맥:** government의 단계 버튼은 div 안의 형제이며 list/tablist가 아니다. aria-expanded는 있지만 패널 보강이 요구하는 안내·절차·방법 등의 이름 패턴을 만족하지 않는다. help 목적만으로 모든 링크를 분류하지 않는 현재 설계에서 이 제어들을 받는 분기가 없다. 분류 전 pagePurpose/context는 보고서에 없어 특정 문맥 추출값을 단정하지 않는다. (`analyzer.ts:204–244,320–349`, `classifier.ts:222–243,254–291`)
- **안내의 주제와 현재 기능 혼동:** library의 검색결과·검색기능은 검색 실행이 아니라 검색 안내 탭인데 일반 검색 문구가 이긴다. role=group 슬라이드 보강은 안내로 끝나는 문맥을 추가로 요구한다. 상세정보와 button 형태 가이드 다운로드는 별도 help 근거를 얻지 못한다. 다운로드 판별도 anchor에 한정된다. (`classifier.ts:7,20,254–291,388–426`, `action-policy.ts:6–9`)
- **학사 개념과 제목 위치:** smu의 전공 제도는 주 학사 문구에 없고 개념 보강은 별도의 학사 문맥을 요구한다. 실제 제목은 탭 뒤의 형제 content 안에 있어 선행·범위 제한 제목 추출로 쓰기 어렵다. 단순한 사이트 경로나 라벨 추가로 맞추기보다 이 구조를 일반화해야 한다. (`classifier.ts:9,39–89`, `analyzer.ts:116–145`)
- **검색 입력/버튼과 고정 제목 연결:** public-agency의 검색 입력은 실제 안전한 원본 제어이나 accepted는 검색 버튼만 지정했다. 입력 내용 유출이나 가짜 기능 생성의 증거가 아니다. 같은 페이지의 필수 외 상세보기 2개도 본문 label은 일반 상세보기, 고정 주제는 형제 item-info/strong/title에 있어 보강이 받지 못한다. (`analyzer.ts:65–94,267–277`, `ranker.ts:88–103`)

## 액션 불일치의 해석

기존 v7의 category/action 오류 0 감사는 인위적 동작 표식이 있던 이전 재구성 fixture에 대한 판정이다. 실제 속성을 복원한 v2의 액션 계약을 확정하는 증거로 전이하지 않는다. 별도 [독립 v2 액션 감사](v7-v2-action-audit.json)와 [root 검토](v7-v2-action-root-review.json)를 완료했으며 기존 감사와 첫 FAIL은 모두 보존한다.

독립 감사는 accepted 액션 **6개**의 확정 주석 충돌을 확인했다. city 예약안내는 role=button·aria-controls/haspopup 때문에 `locate`가 계약에 맞고, 다른 문서로 향하는 smu fragment 링크 5개는 `navigate`가 맞다. 후자는 expected 3개와 smu 공개 과제에도 영향을 준다. city-login·nps-login은 명시 handler 없는 일반 HTTP 로그인 진입이어서 계약 모호성 2건으로 남는다. **주석 충돌·계약 모호성을 실제 선택된 제품 액션 결함으로 합산하지 않는다.**

smu 학사 카드는 첫 평가에서 선택되지 않았으므로 다른 문서 fragment의 주석 충돌은 이번에 관찰된 학사 실행 오류가 아니다. `smu-second`는 원본과 같은 문서 fragment라 `locate`가 맞다. root는 평가기가 fixture를 route한 뒤 실제 페이지 URL로 goto함을 확인했으며, 구조 parity 관찰의 about:blank와 별개다. 이번 체크포인트는 자료 정정·재계산·재평가 없이 **첫 6/12·4/15 FAIL**과 기존 분류 진단·범용 개선 결론을 유지한다.

## 추가 메뉴의 한계와 다음 개발

추가 메뉴도 **6/12·4/15**로 동일하다. 각 페이지는 1화면, 다음 없음, 반복 카드 0이다. sourceId 없는 검색 입력으로 unresolved mapping 1건이 있다. 추가 메뉴는 분류된 overflow만 보여주므로 미분류·오분류를 복구하지 않는다. 이 결과는 축약 fixture의 카드 표시/매핑이며 설치 경로·원본 동작 실행·업무 완료 증거가 아니다.

다음 버전에서는 사이트 ID·수집 라벨·기준값 조정 없이, 서로 다른 DOM 구조로 다음 회귀 주제를 먼저 만든다.

1. 고정 서비스 제목과 날짜·상태 등 부가 문구를 구별하는 카드 근거. 기사·위험 명령·편집 자식은 제외 사례로 유지한다.
2. 목록·role group·일반 형제 버튼의 안내 탭에서 주제와 실제 사용자 과제를 구별하는 근거. 같은 페이지의 무관한 링크는 배제한다.
3. 뒤·옆 영역의 제목을 가진 교육 제도 탭, 일반 상세보기와 형제 고정 제목, button 형태 안내 다운로드.
4. 일반 HTTP 인증 진입·메뉴 trigger·동일/다른 문서 fragment의 정책 계약을 category와 독립 검증한다. 주석 오류가 입증되면 별도 정정판과 근거를 만들고 첫 파일은 대체하지 않는다.
5. 입력값을 읽지 않는 검색 입력/버튼의 과제 중복 및 ID 없는 고정 이름 제어의 매핑을 검토한다. 첫 오탐을 없애기 위해 지표를 바꾸지 않는다.

**S07은 IN_PROGRESS를 유지한다.** 이번에 읽은 동일 5페이지는 이후 개발용이며 새 독립 첫 평가로 재사용할 수 없다. 구현은 별도 버전에서 진행하고 일반화 검증은 새 엔진·새 자료 동결 뒤에 한다.
