## 다음 첫 작업

1. 사용자의 컴퓨터 작업을 방해하지 않도록 native UI 자동화는 중단한다. [1인 사전 테스트](PRETEST.md)로 일반 링크·원본 안내·복귀를 사용자가 편한 때 먼저 시험한다.
2. S08 단축키·새로고침·페이지 이동 후 재실행, S06 실제 VoiceOver 발화는 사용자 수동 결과를 기록한다. 이번 불안정한 AX/프로필 관찰만으로 제품 실패나 통과를 단정하지 않는다.
3. 알려진 평가 자료로 개선한 결과와 새로운 독립 자료의 결과를 구별한다. 새로운 자료에서도 목표를 통과하기 전 S07을 DONE으로 바꾸지 않는다. 정식 사용자 실증도 별도로 진행한다.
