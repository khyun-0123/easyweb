## 다음 첫 작업

1. 사용자의 컴퓨터 작업을 방해하지 않도록 native UI 자동화는 재개하지 않는다. 사용자는 [1인 사전 테스트](PRETEST.md)와 로컬 수동 확인실을 편한 때 직접 시험할 수 있다.
2. v6의 첫 품질 실패를 보존한 상태에서 분류 누락을 조사한다. 현재40페이지는 개발 자료이며, 같은 자료 재평가나 추가 메뉴 합집합을 새 독립 인수 결과로 세지 않는다.
3. 실제 VoiceOver·브라우저200/400%확대·원래 Manifest 설치 경로, 정식 사용자 관찰을 별도로 기록한다. 로컬/헤드리스 검사로 대체하지 않는다.
