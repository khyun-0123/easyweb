## 수동 확인실과 사용자 참여

로컬 확인실은 [http://127.0.0.1:4183/manual-check.html](http://127.0.0.1:4183/manual-check.html)이다. 원본 제어·안내 실패·다시 찾기·다음 페이지 등의 흐름과 기록 양식을 준비했다. 최종 v0.4의 확인실2경로와 `content.js`를 HTTP GET해 **3/3 응답200·로컬 바이트 일치**를 확인했다. 이 과정에서 브라우저를 열거나 스크립트·설치 확장을 실행하지 않았다. 사람의 실제 확인 결과는0이다. [최종 HTTP 무결성](evidence/run003/manual-fixture-final.json)

사용자가 직접 편할 때 [사전 시험](PRETEST.md)과 [접근성 안내](ACCESSIBILITY.md)·[설치 안내](INSTALL.md)를 따라 확인할 수 있다. 실제 VoiceOver 발화·상태·초점, 실제 브라우저 확대, 원래 Manifest의 도구 모음/단축키/페이지 이동 복구는 결과가 제공될 때만 기록한다. 이번 작업에서 native UI를 조작하지 않았다.
