# 지원·검증 범위

현재 버전은 **0.4.0 개발 후보**이며 완료 단계는 **5/10**이다. 표의 기관은 제한된 공개 페이지 검증 대상이며 기관 전체·로그인 업무 지원이나 제휴를 뜻하지 않는다. 결과는 페이지 구조·원본 팝업·시점에 따라 달라질 수 있다. 최종 소스 해시·검사 수치·패키지 해시·인수 상태는 [RUN-003 보고서](RUN_003_REPORT.md)와 [진행표](PROGRESS.md)를 따른다. v0.3.0의 관찰은 [RUN-002 과거 기록](RUN_002_REPORT.md)으로 보존한다.

고정 과제의 원본 문구·정확한 URL·공개 목적지/원본 제어 구분은 [정답 데이터](../evaluation/README.md)에 있다. 축약 fixture 수치, 실제 전체 페이지의 15개 공개 과제, 설치된 확장의 도구 모음 실행, 실제 사용자 실증을 서로 대체하지 않는다.

원래 core와 독립 v2~v6의 첫 평가 후 노출된 자료는 현재 총 **40페이지의 개발 데이터**다. 새 독립 v5·v6의 최초 품질 판정은 모두 **FAIL**이며, v6의 추가 메뉴 흐름 coverage **5/15**도 독립 품질 미달을 해결한 결과가 아니다. v6의 확정 분류 주석 오류 4개(필수 기대 기능 1개 영향)는 [별도 감사](evidence/run003/annotation-taxonomy-audit.json)에만 기록했고 원본 정답·fixture·과제는 유지한다. 자세한 최초 수치는 [평가 이력](../evaluation/README.md)을 따른다.

## 동작 정책

처음에는 최대 6개 메뉴를 보여주며 **다른 메뉴 보기 / 이전 메뉴**로 추가 후보를 탐색한다. 기존 순위와 최초 6개 품질 평가 기준은 유지한다.

일반 HTTP(S) 링크는 사용자의 선택에 따라 직접 이동한다. 명시적 JavaScript·팝업·fragment·인증·다운로드 제어는 원본 위치를 안내하고 사용자가 계속한다. 원본 안내는 초점·가시성·가림·변경 검사를 통과해야 성공 메시지를 낸다. 카드가 표시됐다는 사실은 과제 완료가 아니다.

DOM 표식 없는 property/위임 클릭 이벤트는 확장 isolated world에서 완전히 식별할 수 없다. 일반 링크 카드가 원본 JS/SPA 처리를 우회할 수 있다는 한계가 있다. 불투명한 서버 다운로드 URL과 SSO 경로도 완전하게 식별하지는 못한다. 원본 앱의 모든 행동 보존·업무 성공을 보증하지 않는다. [정의 사례와 실제 world 관찰](ACTION_POLICY.md)을 따른다.

## 환경

- macOS arm64의 Chromium 자동 검사를 사용한다. 별도 Google Chrome for Testing의 네이티브 설치 경로 관찰은 RUN-002의 v0.3.0 과거 기록이다. **현재 v0.4.0 네이티브 설치 경로는 NOT_RUN**이며 사용자 기존 Chrome 프로필은 변경하지 않았다.
- 일반 최상위 HTTP(S) 문서의 현재 보이는 DOM을 분석한다. iframe 내부·닫힌 Shadow DOM은 수집하지 않는다. 열린 Shadow DOM 내부의 재귀 수집도 현재 구현 범위가 아니다.
- Chrome 내부 페이지·웹 스토어 등 주입 제한 페이지는 오류 배지와 일반 페이지 재실행 안내를 사용한다. 제한을 우회하지 않는다.
- 320px 재배치 검사는 좁은 화면 배치 검사다. 모바일 Chrome 확장 실행·Windows Chrome·NVDA 실기기 호환 완료를 뜻하지 않는다.
- **실제 VoiceOver 발화·상태 안내, 실제 브라우저 확대, 현재 v0.4.0의 수동 복구는 미검증**이다. [수동 확인 안내](MANUAL_CHECK.md)와 <http://127.0.0.1:4183/manual-check.html>를 사용하고 실제 관찰 후 기록한다. 자동 AX·키보드·좁은 화면 검사를 실제 발화·실제 브라우저 확대 통과로 바꾸지 않는다.
- 실제 사용자 실증 관찰은 **0건 / NOT_RUN**이다. [접근성 문서](ACCESSIBILITY.md), [1인 사전 시험](PRETEST.md), [정식 실증 문서](USER_STUDY.md)의 범위를 구별한다.

## 보고할 때

공개 페이지 URL, 후보 버전, Chrome 버전, 선택한 카드의 고정 이름, 기대/실제 결과, 재현 순서를 기록한다. 로그인 정보·입력 내용·비공개 화면은 넣지 않는다. `카드 없음`, `다른 목적지`, `원본 가림`, `초점 실패`, `변경 안내`, `복귀 실패`처럼 관찰한 사건을 구분하면 재현에 도움이 된다.
