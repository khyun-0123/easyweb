# **05 handoff**

EasyWeb · 1인 프로젝트
버전: v1 (2026-10-31, v0.10.0 기준) · 상세 정책: [ACTION_POLICY](ACTION_POLICY.md) · [SUPPORT_MATRIX](SUPPORT_MATRIX.md) · [ACCESSIBILITY](ACCESSIBILITY.md)

**이 문서는 최종 문서입니다.** 다른 사람(또는 나중의 나)이 이 프로젝트를 이어받을 때 반드시 알아야 할 경계만 적습니다. 바뀌면 덮어씁니다.

질문: 저장 위치 / 권한 / 외부 통신 / 개인정보 / 원본 실행 / 실패 조건 / 지원 범위 / 검증 경계

- **저장 위치 >** 없음. 분석 결과·카드는 화면이 열린 동안 메모리에만 있고 닫으면 사라짐. 확장 저장소·쿠키·서버를 쓰지 않음
- **권한 >** `activeTab` + `scripting`만. 사용자가 버튼을 누른 탭에서만 실행. 모든 사이트 상시 접근, 원격 호스트 권한, 추가 권한을 넣지 않음. 기능을 위해 권한을 늘리는 변경은 07에 결정 항목으로 먼저 올림
- **외부 통신 >** 없음. 분석 결과를 어디로도 보내지 않음. 원격 LLM·유료 API·분석 서버를 제품에 넣지 않음 (로컬 AI 시험도 개발 도구로만, [09](09_local_ai_review.md))
- **개인정보 >** input·textarea·contenteditable·편집 role·중첩된 사적 값을 후보·화면·로그·저장소에 넣지 않음. value·checked·편집 내용을 읽지 않음. 고정 메타데이터와 안전한 이름만 읽음
- **원본 실행 >** 원본 제어의 `click()`·이벤트 전달·폼 제출·인증·결제·삭제를 하지 않음
  - 일반 HTTP(S) 링크 → 카드에서 바로 이동 (사용자 확정)
  - 명시적 JavaScript·handler·팝업·다운로드·SSO·같은 문서 fragment → 원본 위치 안내
  - 일반 로그인 폼으로 가는 링크·다른 문서 fragment → 일반 링크
- **실패 조건 >**
  - 원본이 바뀜·사라짐·숨겨짐 → 카드 실행을 막고 "원본 페이지가 바뀌었어요. 다시 찾기를 눌러주세요."
  - 원본 위치 안내 중 가려짐·초점 실패 → 원본 위에 실패 안내와 「안내 닫기」
  - 주입이 막힌 페이지(Chrome 내부·웹 스토어) → 도구 모음에 `!`와 "일반 웹사이트에서 다시 실행"
  - 주요 기능을 못 찾음 → "주요 기능을 찾지 못했어요"와 원본 화면 보기
- **지원 범위 >** macOS 데스크톱 Chrome, 일반 최상위 HTTP(S) 문서의 보이는 DOM. iframe 내부·닫힌/열린 Shadow DOM 내부는 수집하지 않음. 모바일 Chrome·Windows는 미확인
- **알려진 한계 >** DOM 표식 없는 property/위임 클릭 이벤트는 알 수 없어서, 일반 링크 카드가 원본 JS/SPA 처리를 건너뛸 수 있음. 불투명한 다운로드 URL·SSO 경로를 모두 식별하지는 못함
- **금지 >** 평가 ID·문서 번호·불투명 query·정답 순서를 규칙에 매핑하지 않음. 읽기 예외로 위험 URL/query/script 검사를 우회하지 않음

handoff: **검증 경계** — 자동 검사(로컬 493개·접근성 21조건·합성 성능), 개발 자료 평가(60페이지), 처음 보는 자료 평가, 실제 설치, VoiceOver 발화, 실제 확대, 사람 실증은 **서로 대신하지 않습니다.** 하나가 통과해도 다른 것을 통과로 적지 않습니다. 첫 평가 결과·동결 해시·ZIP은 고치지 않고 보존합니다 ([evidence/](evidence/)).

handoff: **작업 환경** — 사용자의 보이는 브라우저·창·초점·키보드·기존 Chrome 프로필을 자동으로 조작하지 않습니다. CLI와 별도 headless만 씁니다. 로컬 데모 서버 4173/4183은 중지·재시작하지 않습니다.
