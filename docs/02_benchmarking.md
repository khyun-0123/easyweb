# **02 벤치마킹 스크랩**

EasyWeb · 1인 프로젝트

이 문서는 **쌓는 문서**입니다. 지우지 않고 계속 붙입니다. 화면 캡처, 링크, 메모 무엇이든 그대로 붙여 넣고, 정리는 나중에 합니다.

베끼려고 보는 것이 아니라, **우리가 다르게 할 한 가지**를 찾으러 봅니다. 이미 잘 되어 있는 것은 만들지 않습니다.

## **지금까지의 결론**

조사할 때마다 이 두 줄을 고쳐 씁니다. 이 줄이 [01 PRD](01_prd.md)의 Q3으로 올라갑니다.

**우리가 다르게 할 한 가지 :** 화면을 확대하거나 문제를 알려 주는 것이 아니라, 지금 페이지에서 **실제로 있는 주요 기능을 골라 큰 버튼으로 다시 보여 주고 원본과 안전하게 연결**하는 것 (지원서 Q3-1)

**우리가 만들지 않을 것 (이미 있는 것) :** 화면 확대·글자 크기 조절(브라우저 기본 기능), 접근성 문제 검사·리포트(검사 도구), 화면 읽기(스크린리더) — *아래 조사로 확인 필요*

> 현재 상태: 위 결론은 지원서 작성 때의 판단이며, **비슷한 서비스를 직접 써 보고 기록한 스크랩은 아직 0건**입니다. 아래 후보부터 하나씩 채웁니다. 조사하지 않은 서비스의 기능을 추측해서 적지 않습니다.
