# **실제 페이지 첫 6개 카드 검토 — 2026-10-31**

EasyWeb v0.10.0 · 기록 문서 (결과를 고치지 않음)

**계기:** 개발자가 그램(Windows Chrome)에서 직접 써 보고 "UI는 괜찮은데 카드에 띄워주는 기능이 별로다, 뭘 보여줘야 할지 제대로 못 골라온다"고 판단함.

---

## 1. 무엇을 했나

1. 평가에 쓰던 5개 기관 15개 **실제 공개 페이지**를 headless로 열어 HTML을 저장함 (`tmp/live-html-20261031/`, git 제외). 클릭·입력 없음.
2. 보이는 링크·버튼·검색창 1,334개를 위치·영역·주변 제목과 함께 정리함 → [live-elements](../evidence/feedback-20261031/live-elements/). 입력창은 이름표만 기록하고 값은 읽지 않음.
3. **엔진 결과를 보지 않은 검토자 3명(별도 AI 에이전트)**이 페이지마다 "할머니가 이 페이지에서 가장 필요할 기능" 최대 6개를 고름 → [importance-review](../evidence/feedback-20261031/importance-review/)
4. 같은 페이지에서 엔진이 고른 처음 6개([live-first6](../evidence/feedback-20261031/live-first6/first-six.json))와 비교함 → [comparison.json](../evidence/feedback-20261031/comparison.json)

**한계:** 기준은 실제 사용자가 아니라 AI 검토자의 판단입니다. 비교는 이름 매칭이라 근사치입니다(예: 상명대 "학사안내"는 검토자가 학사일정과 같은 기능으로 봤지만 매칭에서는 빠짐). 15페이지는 이미 개발에 노출된 자료라 독립 평가가 아닙니다.
