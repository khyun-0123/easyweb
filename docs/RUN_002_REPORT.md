버전: **0.3.0 개발 후보** · 시작: **2026-10-18 01:04:05 KST** · 기술 검증 기록 기준: **02:04:05 KST** · 경과 **60분** (이후 문서·로컬 인계 작업은 별도)

현재 **S01~S05, 5/10 단계 완료**다. S08은 최종 빌드의 일부 native 검증을 마쳤지만 단축키·새로고침·페이지 이동 후 재실행이 미판정이다. 사용자의 컴퓨터 작업을 위해 UI 자동화를 중단했다. 실행 가능한 후보와 검증·실증·인계 도구를 만들었지만, 실제 VoiceOver 발화, 새로운 페이지의 기능 재현율, 정식 사용자 실증의 필수 조건이 남아 있어 v1.0 또는 전체 10/10 완료로 판정하지 않는다.

## 사용자 결정과 제품 동작

사용자는 **“일반 링크는 바로 이동 유지”**를 선택했다. 일반 HTTP(S) 링크 카드는 실제 원본 URL과 target으로 이동하고, fragment·명시적 JavaScript/팝업·다운로드·인증 제어는 원본 위치로 돌아가 초점과 임시 강조를 제공한다. 위치 안내에서 원본 click·submit을 자동 호출하지 않는다. 목적지 도메인과 새 창 정보도 표시한다.

페이지가 property `onclick`이나 위임 이벤트로 연결한 동작은 확장 isolated world의 DOM 정보만으로 완전히 식별할 수 없다. 일반 링크 직접 이동이 해당 원본 handler·SPA router를 우회할 수 있다는 한계를 남긴다. 모든 원본 JavaScript 동작 보존을 입증했다는 주장이 아니다. [액션 정책과 검증 범위](ACTION_POLICY.md)

사용자는 **“내가 컴퓨터로 작업해야 돼서 되도록 컴퓨터 유즈 사용하지 마”**라고 추가로 요청했다. 포커스를 바꾸는 native 앱·브라우저 자동화를 모두 중단했으며 남은 확인은 수동 안내로 남긴다. 터미널·헤드리스 검증과 로컬 자료 정리는 별도로 수행했다.

사용자는 **“내가 먼저 시험해볼 수 있음”**이라고 답했다. 1인 사전 테스트 안내와 빈 기록 양식을 준비했으며 실제 결과는 아직 없다. 이를 정식 대상 사용자 6~8명의 사용성 실증이나 시간 단축 달성으로 계산하지 않는다. [먼저 시험하기](PRETEST.md) · [정식 실증 설계](USER_STUDY.md)

## 공개 과제 검사의 범위

공개 과제 15개는 같은 이름과 실제 공개 href로 원본 제어를 대응시켰다. 일반 링크는 실제 카드 링크를 선택해 정확한 공개 목적지·HTTP 응답을 확인하고, locate는 원본의 초점·화면 내 위치·상태 안내를 확인한다. 로그인·인증·입력·폼 제출·실제 신청·다운로드를 자동 수행하지 않는다. 따라서 15/15가 기록되더라도 **업무 완료율 또는 사람이 시험한 성공률을 뜻하지 않는다.**

실사이트 자동화는 새 비로그인 Playwright context와 CDP isolated world에 현재 소스를 묶어 주입한 것이다. 도서관 페이지의 main-world 평가/엄격한 CSP 차이도 검사 경로와 분리했다. 원래 Manifest를 설치한 실제 도구 모음 검사는 S08의 native 기록만 사용한다.

`tasks-live-final.json`의 최종 결과는 **15/15**, 공개 링크 목적지 9개·원본 안내 6개·안내 재시도 0이다. 중간 변경 소스에서 천안시 홈의 명시적 상담 기능이 전역 메뉴에 밀려 14/15로 퇴행한 결과 두 건도 `priorSnapshots`에 보존했다. 명확한 본문 도움 기능의 근거를 보강한 뒤 같은 최종 소스로 전체 15과제를 다시 통과했다. [실제 과제 기록](evidence/run002/tasks-live-final.json)

## 실증과 인계

정식 실증은 6/7/8명에 대해 60/70/80 trials, 사이트당 6/7/8개의 짝지어진 과제를 배정하도록 준비했다. 실패·timeout·blocked·withdrawn을 분모에서 조용히 빼지 않으며, 시간 비교는 동일 참여자·동일 과제에서 양쪽 모두 성공한 쌍만 사용한다. 원래 화면과 EasyWeb 양쪽의 실제 결과가 없으므로 현재 제품 개선 판정은 NOT_EVALUATED다. [실제 데이터 미실시 확인](evidence/run002/study-not-run.json)
