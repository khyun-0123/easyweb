EasyWeb 수동 확인실

합성 메뉴 전용 · 실제 기관·계정·검색·신청이 아닙니다. 입력창, 자동 제출, 외부 통신, 팝업, 기록 저장이 없습니다. 이 페이지는 EasyWeb을 자동으로 열지 않습니다.

설치한 확장의 도구 모음 버튼 또는 설정된 단축키로 쉬운 화면을 여세요. 실제 VoiceOver 음성·브라우저 200%/400% 확대·설치 복구는 사람이 확인하고 기록해야 합니다. 이 페이지를 열었다는 사실만으로 통과가 되지 않습니다.

원본 메뉴

쉬운 화면의 통합검색은 이 버튼 위치만 안내해야 합니다. 안내 직후 아래 실행 횟수는 0이어야 합니다. 원본 버튼을 직접 누르면 합성 횟수만 1 증가합니다.

공지사항

원본 버튼 실행 횟수: 0 · 아직 직접 누르지 않았습니다.

공지사항 링크는 같은 확인실의 다음 화면으로 바로 이동합니다. 이 링크로 이동·뒤로 가기·재실행을 검사할 수 있습니다.

실패 상황 준비

한 번에 하나만 준비하세요. 선택 후 10초 안에 확장으로 쉬운 화면을 열고, 준비 표시가 끝날 때까지 기다리세요. 쉬운 화면이 열려 있어도 예약은 진행됩니다. 매 시험 전 초기화하거나 페이지를 새로고침하세요.

대기 중 · 예약 없음

메뉴 바꾸기는 통합검색을 자료 검색으로 바꿉니다. 이전 카드는 실행되지 않아야 하며 ‘다시 찾기’ 후 새 메뉴를 확인하세요. 가림막은 원본을 가리지만 쉬운 화면 위로 덮지 않습니다. 가린 상태에서 통합검색 카드를 선택하면 성공 대신 가려짐 안내가 나와야 합니다.

가림막은 나타난 뒤 45초 후 자동으로 없어집니다. 화면을 가려도 키 입력을 가로채거나 초점을 자동으로 이동하지 않습니다. 새로고침으로 언제든 초기 상태로 돌아올 수 있습니다.

자료 버튼 구분 시험

같은 이름의 ‘자료받기’를 관련 서식 제목으로 구분하고 추가 메뉴를 오가는 시험입니다. 실제 파일이나 다운로드는 없습니다. 먼저 켠 뒤 확장을 여세요.

직접 확인할 순서

  1. 아무 예약 없이 확장을 여세요. Tab/Shift+Tab, 다시 찾기, Esc, 재실행을 확인하세요.
  2. VoiceOver에서 제목·각 카드의 링크/버튼 역할·다시 찾기 상태를 실제로 듣고 기록하세요.
  3. 통합검색 카드를 선택해 원본 초점·강조와 성공 안내를 확인하세요. 자동 실행 횟수는 0이어야 합니다.
  4. 초기화한 뒤 각 실패 상황을 예약하고, 10초 안에 확장을 열어 변경/가려짐 안내를 각각 확인하세요.
  5. 브라우저 메뉴의 실제 확대를 200%, 400%로 바꿔 모든 카드·닫기·다시 찾기를 사용할 수 있는지 확인한 뒤 원래 확대를 복원하세요.
  6. 공지사항 카드로 다음 화면 이동 → 확장 재실행 → 새로고침 → 확장 재실행 → 뒤로 가기를 확인하세요.

전체 절차와 빈 결과표: 프로젝트의 docs/MANUAL_CHECK.md. 실제 결과는 아직 NOT_RUN입니다. 실제 기관 5개 페이지의 설치 실행 확인이나 정식 사용자 실증을 대신하지 않습니다.

EasyWeb 개발용 확인실 · 개인정보를 입력하지 마세요. 페이지를 닫으면 예약과 합성 횟수가 사라집니다.

합성 가림막이 원본을 가리고 있습니다

쉬운 화면에서 통합검색을 선택하면 ‘다른 창에 가려져 있어요’ 안내가 예상됩니다. 원본 기능은 실행되면 안 됩니다. 이 가림막은 45초 뒤 자동으로 사라집니다.
